# Cube Chaos — плоский интерфейс

Источник UX-рекомендаций: [UI/UX Pro Max](https://github.com/Meidelg/codex-agents/blob/main/.agents/skills/ui-ux-pro-max/SKILL.md), версия из личного профиля пользователя. Навык прочитан через подключённый GitHub; его поиск выполнен локально без установки всего профиля.

Проверенные результаты поиска:

- `flat design minimal --domain style`: активный стиль `flat-design` — плоские поверхности, сплошные цвета, простая геометрия, без теней и градиентов.
- `icon button accessible label --domain icons`: векторная иконка сама декоративная, кнопка получает доступное имя, состояние выражается семантически.
- `touch target size --domain ux`: удобные зоны нажатия с учётом платформы; нативные pt/dp не приравниваются к требованиям web CSS px.

## Решения пользователя

- Без логотипа, рекламных надписей, теней, бликов, градиентов и декоративного размытия.
- Главная: баланс и четыре действия. Остальные экраны занимают всю доступную высоту с учётом safe-area.
- Назад: визуальная кнопка со стрелкой, `aria-label` и `title`, без видимого текста.
- Магазин: четыре товара на странице, сетка 2 × 2. Последняя страница может быть неполной; длинные каталоги пагинируются.
- Единственная вертикально прокручиваемая область — история гонок.
- Кубики и геометрия трассы тоже рисуются без теней. Стены имеют физическую клеточную структуру 1 × 1. В игре они выглядят сплошной поверхностью одного цвета с внешним фоном, без сетки и швов; сетка остаётся в редакторе.

## Проверка реализации

Использовать общие семантические цвета, контрастный текст, видимое состояние клавиатурного фокуса, реакцию на нажатие без сдвига компоновки и `prefers-reduced-motion`. У стрелок и системных действий сохранять доступные названия. Состояния участников обозначать номером и текстом, а не одним цветом.

Проверка кода и тесты не заменяют измерение видимых размеров, системного масштаба текста и safe-area на реальном iPhone. Непроведённые проверки не считать выполненными.


Проверенные контрастные пары CSS-токенов: основной текст/фон 13,88:1; вторичный текст/фон 5,85:1; вторичный текст/белая поверхность 6,39:1; текст основной кнопки/акцент 7,56:1. Это расчёт токенов исходного CSS; он не заменяет визуальную проверку композиции и системного увеличения текста.
