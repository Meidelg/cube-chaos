# Cube Chaos · 0.12.0

Локальная 2D-игра на JavaScript, PixiJS 8 и Matter.js. Первый рабочий вариант по ТЗ 1.0 и уточнениям из обсуждения. Результаты определяет физическая симуляция; предварительного выбора победителя и управления движением через AI нет.

## Запуск

```sh
npm install
npm run dev
```

```sh
npm test
npm run build
```

`dist/` — автономная статическая сборка. Размещать по HTTPS (или localhost для разработки). Все библиотеки включены в сборку; сторонние CDN не используются. Звук и фоновая музыка синтезируются Web Audio локально после первого действия пользователя.

## Устройство

- `config.js` — параметры мира и фиксированный шаг (пока 120 Гц, подлежит проверке на iPhone).
- `physics.js` — Matter.js, скорость, контакты, раздавливание и безопасные позиции.
- `modules.js`, `map.js` — модульные ассеты, повороты, генерация по seed и граф маршрутов.
- `mechanisms.js` — роторы, прессы, отбойники, конвейеры, ускорители, замедлители, телепорты, лазеры, изменение размера и составная стена.
- `breakables.js` — четыре разрушаемых препятствия, цветовые условия и учёт отдельных физических ударов.
- `race.js`, `prediction.js` — жизненный цикл гонки, события победы и прогнозы.
- `renderer.js`, `camera.js` — отрисовка и мышь / touch / pinch.
- `save.js`, `shop.js` — транзакции IndexedDB, резервная копия, экономика и косметика.
- `ui.js`, `style.css` — адаптивный интерфейс на русском.
- `audio.js` — локальный звук, лимит голосов, отдельная громкость музыки и эффектов.
- `pwa.js`, `scripts/offline.mjs` — полное предварительное кеширование сборки и отложенное обновление.
- `single-tab.js` — одна активная вкладка в одном браузерном хранилище.
- `game.js` — управление экранами, связывание систем и цикл времени; `main.js` — запуск приложения.

## Управление

Выбрать 2–12 участников, размер трассы, затем кубик и «Начать гонку». Карту можно перетаскивать мышью или пальцем. Колесо и жест двумя пальцами меняют масштаб. Скорости ×1/×2/×4/×8 исполняют одинаковые физические шаги. Пробел — пауза. Кнопки справа под картой показывают всю трассу, сбрасывают камеру и скрывают HUD.

Прогноз можно менять до 5,1 игровой секунды включительно. Таймер на экране заканчивается на 5,0. После 5,0 гибель выбранного кубика делает прогноз окончательно проигрышным. Финиш требует полного попадания текущего коллайдера. Нулевая скорость не исправляется случайным толчком. Импульс от отбойника затухает сразу и заканчивается через игровую секунду. Активация изменения размера хранится отдельно для каждой пары кубик/объект.

## Сохранения

Баланс, покупки, статистика, завершённые гонки и снимок гонки хранятся одной записью IndexedDB. Начисление награды и фиксация результата — одна транзакция, идентификаторы гонок защищают от повторного начисления. Последняя корректная запись хранится отдельно. Настройки дополнительно сохраняются в localStorage.

Автосохранение — раз в две реальные секунды и при уходе в фон. Возврат всегда на паузе, фоновое время не симулируется. ОС может прервать последнюю запись; возможна потеря последних секунд. Сохранение из новой версии блокирует загрузку старой игрой без удаления данных. JSON-экспорт начинается с `gameVersion`, содержит отдельную версию формата и контрольную сумму. Это проверка целостности, не защита от намеренного редактирования локального прогресса.

## Офлайн на iPhone

Открыть HTTPS-версию в Safari, дождаться «Готово к офлайн-игре», затем «Поделиться → На экран Домой». Повторно открыть с иконки и проверить запуск в авиарежиме. Не активировать обновление посреди гонки без сохранения и согласия игрока. Экспортировать резервные копии: iOS может удалить хранилище.

## Проверки и текущие ограничения

Автоматические проверки охватывают генерацию 300 карт, физические отскоки, отсутствие самопроизвольных толчков, раздавливание, полное попадание на финиш, одновременные смерти, границу прогноза, восстановление, целостность сохранений и идемпотентность экономики. Дополнительно выполнены прогоны 50 небольших карт с 12 участниками: незавершённых гонок после 180 игровых секунд не обнаружено. Это выборочная проверка, не доказательство завершения любой карты.

Физический шаг, критерии сжатия и траектории преследующей стены требуют дальнейшей проверки сложных комбинаций. Для событий внутри одного физического шага используется одна временная отметка; совпадение разрешается PRNG, порядок callback не используется. Восстановление не обещает побитового совпадения будущих столкновений Matter.js. iPhone 14 / iOS 27 и реальный офлайн-запуск должны пройти отдельную приёмку на устройстве; десктопная проверка их не заменяет.

## Изменения 0.3.0

Части карты задаются буквальными строками `grid`: `а` — стена, `б` — воздух. Одна клетка равна 1 × 1 игровому юниту (`U` пикселей). Например, рисунок ниже сохраняет все 16 клеток в исходных позициях:

```text
аааа
ббба
ббба
абба
```

`parseTileGrid` проверяет прямоугольность и символы, выделяет стеновые клетки и проходимую геометрию. `instantiateModule` поворачивает исходные строки вместе с портами. Физические коллайдеры могут объединять соседние стеновые клетки для производительности; отрисовка сохраняет сетку 1 × 1. Внутренние стены авторского рисунка участвуют в столкновениях. Узкие примеры допустимы для парсера, но игровые модули сохраняют нужные просветы для кубиков и механизмов.

Начальные скорости новых гонок направлены только по четырём диагоналям: 45°, 135°, 225°, 315°, с одинаковой нормой `BASE_SPEED`. Это ограничение не применяется к восстановленным скоростям или к направлениям после столкновений.

Интерфейс следует плоскому стилю UI/UX Pro Max из профиля пользователя, с явными пользовательскими ограничениями. См. `design-system/cube-chaos/MASTER.md`. Убраны тени, градиенты, блики и декоративное размытие. Назад — SVG-кнопка с доступным названием. Магазин показывает до четырёх товаров на странице в сетке 2 × 2; неполная последняя страница допустима. Вся необходимая графика и библиотеки остаются локальными.


Проверки 0.3.0: 46 автоматических тестов проходят. Дополнительно завершены 9 гонок с 12 участниками на трёх размерах карт, включая финиш, последнего выжившего и последнего погибшего. ## Изменения 0.4.0

Добавлены четыре типа объектов:

| Тип | Кто наносит урон | Как разрушается |
| --- | --- | --- |
| Цветной блок | Кубик того же цвета | За один удар; каждая клетка ряда разрушается отдельно |
| Универсальный блок | Любой кубик | За один удар; каждая клетка ряда разрушается отдельно |
| Цветная стена со счётчиком | Кубик того же цвета | После указанного числа ударов, вся стена целиком |
| Универсальная стена со счётчиком | Любой кубик | После указанного числа ударов, вся стена целиком |

Все препятствия имеют толщину 1 игровой блок. Ряды состоят из отдельных клеток 1 × 1. Счётчик цельной стены отображается на самой стене и уменьшается после каждого подходящего удара. В генераторе начальное число ударов выбирается в диапазоне 3–8; параметры находятся в данных механизма.

Урон обрабатывается после полного физического шага Matter.js: кубик сначала отскакивает от твёрдой поверхности, затем исчезает разрушенный коллайдер. На последнем ударе кубик не пролетает сразу сквозь стену. Неподходящий цвет тоже отскакивает, но не уменьшает прочность. Непрерывное прижатие не считается множеством ударов; следующий удар требует разрыва контакта. Одновременные столкновения решаются движком до удаления стены.

Цветной барьер получает цвет одного из участников через colorSlot; совпадение определяется фактическим цветом, включая одинаковые цвета у нескольких кубиков. Палитра и цвета препятствий фиксируются на текущую гонку. Изменение палитры в настройках после старта применяется к следующей гонке, чтобы оформление не меняло доступ к проходам посреди симуляции.

Снимок гонки сохраняет оставшиеся удары, цвета, удалённые клетки и активные контакты. Восстановление не начисляет лишний удар за уже существовавшее касание. Преследующая стена поглощает все четыре объекта. Генератор версии 4 учитывает траектории других механизмов и сохраняет альтернативный путь вокруг цветных стен на обходах; старые сохранённые карты версий 1–3 читаются в исходном виде.


Проверки 0.4.0: 65 автоматических тестов проходят. Новые сценарии проверяют настоящий отскок по обеим осям перед удалением коллайдера, неподходящий цвет, независимые клетки ряда, счётчик отдельных ударов, одновременные попадания, восстановление повреждений/контактов и поглощение преследующей стеной. Дополнительно завершены 6 гонок с 12 участниками на трёх размерах карт.

## Изменения 0.5.0

Исправлен пропадающий отскок при пологом столкновении с неподвижной стеной: после настоящего контакта Matter восстанавливается недостающий упругий импульс по нормали поверхности. Убран допуск проникновения, который удерживал медленно отходящий кубик возле стены. Отражённая составляющая конвейера учитывается при следующем физическом шаге. Нулевое движение не получает искусственного толчка; прессы и вращающиеся механизмы продолжают обрабатываться движком.

Редактор открывается через **Настройки → Редактор частей**. Поле размером от 4×4 до 32×32 клеток, каждая клетка — 1×1 игровой юнит. Инструменты: стена, воздух, начало секции, конец секции, начало движущейся стены и перемещение камеры. У маркеров задаётся направление; у соединений — ширина. Есть отмена, масштабирование, сенсорное рисование и жест двумя пальцами. В компактном интерфейсе используются вкладки «Поле», «Параметры», «Библиотека» без вертикальной прокрутки страницы.

Сохраняется до 64 частей. Включённые части реально используются генератором версии 5 вместе с переходами к стандартным соединениям. Seed повторяет карту при одинаковой активной библиотеке и версии генератора. Проверяются сетка, связность, проход от входа до выхода, маркеры и совместимость внешних соединений. Если соединения не помещаются рядом с другими частями, часть можно сохранить с выключенным флажком «Для генератора» и затем исправить. Правки библиотеки применяются к новым трассам; начатая гонка сохраняет собственную геометрию.

Библиотека входит в обычное сохранение прогресса, а также экспортируется и импортируется отдельно в JSON. Импорт частей объединяет библиотеку по идентификаторам после подтверждения. Невалидный импорт не заменяет монеты, покупки или незавершённую гонку. Старые сохранения и полные карты генераторов 1–4 поддерживаются.

Проверки: 89 автоматических тестов, production-сборка и локальные ресурсы офлайн-манифеста. Браузерная визуальная проверка недоступна: managed preview не смог открыть порт (EPERM); приёмка на iPhone остаётся непроверенной.

## Изменения 0.6.0

Маркеры начала и конца секции рисуются отдельными клетками 1×1. Соседние клетки расширяют проход; повторное отдельное нажатие на крайнюю клетку сокращает его. Настройка ширины числом удалена. Проход шириной 1 клетка разрешён; увеличенный кубик может через него не пройти.

Генератор версии 6 соединяет входы и выходы разной ширины напрямую. Узкий проход целиком накладывается на широкий с одним из допустимых целочисленных смещений: для 3→1 это левое, центральное или правое положение. Выбор зависит от seed. Клетки не растягиваются, переходные секции для выравнивания ширины не требуются. Неиспользованные участки стыка закрываются стенами. Исходные клетки части сохраняются в её библиотеке; замыкания относятся к собранной трассе.

Старые полосы маркеров и полные сохранённые карты читаются в исходном формате. Обновлённые правила применяются к новым трассам. Визуальная проверка на iPhone остаётся отдельной приёмкой.

Статические стены и внешний фон карты используют один цвет выбранной темы. Линии между клетками убраны, стены отрисовываются сплошной заливкой по объединённым коллайдерам. Клеточная сетка остаётся в редакторе, а контуры коллайдеров — в режиме отладки. Физика и геометрия от этого визуального изменения не меняются.

Проверки 0.6.0: 103 автоматических теста проходят; production-сборка и офлайн-ресурсы подготовлены. Отдельно проверены все три смещения реального стыка custom3→custom1, отсутствие незаявленных обходов, проход кубика 1×1, старые маркеры, сохранения и 40 сложных генераций граничного коридора.

## Изменения 0.7.0

В редактор добавлена вкладка «Объекты» с пагинацией по четыре инструмента. Доступны четыре разрушаемых препятствия, вращающаяся лопасть, пресс, отбойник, конвейер, ускоритель, замедлитель, увеличение размера, парные телепорты и лазер. Объект можно выделить, удалить, повернуть и настроить; у стен задаются длина, число ударов и цвет участника. Лазер создаётся двумя клетками на одной строке или колонке: между ними появляется луч. Телепорты также ставятся парой. Незавершённая пара не записывается в сохранение.

Для начала и конца секции доступна кнопка поворота на поле. Генератор поворачивает всю секцию на 90°, 180° или 270° вместе с механизмами, лучами, эмиттерами, направлениями прессов/конвейеров и начальным углом лопасти. Авторские объекты не заменяются случайными препятствиями. На стыках защищается полная область движения механизма. Идентификаторы и пары телепортов уникальны для каждого экземпляра части.

Обводка убрана у статических стен, прессов и разрушаемых препятствий; сетка остаётся только на воздухе в редакторе. Выделение редактируемого объекта, числа прочности и трещины сохраняются.

Дополнительный объект «Пуск стены» позволяет размещать несколько поворотных стартов движущихся стен. Первая стена запускается по таймеру карты; дополнительные ждут фактического касания другой преследующей стены. После касания начинается новая стена в направлении стрелки. Каждый старт срабатывает один раз. Запущенные стены и время их активации входят в снимок гонки, поэтому после восстановления цепочка продолжается.

Старые библиотеки без объектов и полные карты генераторов 1–6 сохраняют совместимость. Версия генератора новых трасс — 7. Проверки браузерного отображения и реального iPhone не заменяются автоматическими тестами и остаются отдельной приёмкой.

## Изменения 0.11.0

Добавлены две кнопки камеры: прицел следует за кубиком, выбранным в прогнозе; корона — за текущим лидером по прогрессу на маршрутах карты. Лидер меняется автоматически. При равном прогрессе текущая цель сохраняется, чтобы камера не переключалась между одинаково расположенными участниками.

Слежение включается по желанию. Повторное нажатие отключает режим; перетаскивание карты, показ всей карты и сброс также возвращают ручное управление. Колёсико и жест масштабирования сохраняют слежение. Выбранный режим выделяется, на кнопке отображается номер цели. На узком экране управление камерой занимает отдельную строку без прокрутки страницы.

Камера приближает цель при включении и плавно перемещается в реальном времени. Ограничитель удерживает быстрый кубик в видимой области на ×8, а телепортация не оставляет его за экраном. Смена косметики не сбрасывает режим и масштаб. При гибели выбранного участника слежение за ним отключается; режим лидера переключается на другого живого участника, а после окончания гонки показывает победителя. Режим «выбранный» сохраняет своего живого участника даже после победы другого кубика.

Прогноз, награды, физика, скорость симуляции и генерация карт от слежения не меняются. Версия генератора остаётся 10. После создания новой гонки или восстановления из файла камера начинает в ручном режиме.

## Изменения 0.12.0

Перед генерацией доступны отдельные переключатели случайных лазеров, порталов, лопастей, прессов, отбойников, конвейеров, ускорителей, замедлителей, изменения размера и разрушаемых препятствий. Авторские объекты не фильтруются. Terrain для одного seed остаётся прежним; настройка сохраняется отдельно и учитывается навигацией. Версия генератора — 11, сохранённые карты 1–10 совместимы.

Каталог заменён: четыре бесплатных базовых оформления, новые темы Неон/Бумажная/Ночь, шесть скинов, четыре следа и пять финишей. Цены редкостей — 250/500/1000/2500. Бесплатные предметы всегда первые, затем редкость возрастает; на странице четыре карточки. Старые покупки сопоставляются новым предметам без списаний и потери монет.

Отладка разрешает временную примерку всех предметов без покупки и сохранения применения. При выключении отладки возвращается настоящее оформление. Отложенные покупки отменяются при переключении режима.

Новые эффекты рисуются отдельно от физики и PRNG. Неон синхронно меняет контуры, Ночь подсвечивает кубиков их цветами, Бумажная использует локальную процедурную текстуру. Круглая форма не меняет коллизию. Постоянная полоса не имеет временного лимита: исчезает при гибели или полном закрытии сегмента движущимися стенами; её история сохраняется в незавершённой гонке. Призраки сохраняют размер и начинаются с прозрачности 50%. Финиши получают ограниченные своей областью белые блики. Режим снижения эффектов сохраняет игровые правила.

GitHub Pages: `npm run build:pages` создаёт `pages/` с готовой игрой в корне и полными исходниками в `game/`. Размещение — main / root. Vite base, manifest, иконки и Service Worker поддерживают корень домена и /cube-chaos/. Кеши разделены по области регистрации, поэтому обновление одной игры не очищает кеш другого приложения того же домена. Прогресс между разными доменами переносится экспортом/импортом JSON.
